# skbbjaveria_bloodcancer_project
“AI-Based Blood Cancer Detection from Peripheral Blood Smear Images.”  The main objective of our project is to automatically detect leukemia using deep learning techniques, reducing the dependency on manual diagnosis. Traditionally, blood cancer detection is done manually using microscopes, which is time-consuming, requires expert doctors.
This project presents an AI-powered system for detecting blood cancer, particularly leukemia, from peripheral blood smear images using Deep Learning and Image Processing techniques. Traditional leukemia diagnosis through microscopic examination is time-consuming, subjective, and highly dependent on expert hematologists. To overcome these limitations, this system uses Convolutional Neural Networks (CNNs) and advanced image preprocessing methods to automatically analyze blood smear images and classify them as healthy or cancerous. The workflow includes image preprocessing, segmentation, feature extraction, and deep learning-based classification to achieve fast and accurate prediction results. The project utilizes datasets such as ALL-IDB1 and ALL-IDB2 and is implemented using Python, TensorFlow/Keras, OpenCV, and Jupyter Notebook. The proposed system aims to reduce manual workload, improve diagnostic consistency, support early cancer detection, and provide an efficient solution for clinical pathology labs, telemedicine platforms, and hospital diagnostic systems.
